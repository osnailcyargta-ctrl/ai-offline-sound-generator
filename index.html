Before you report a bug

  • Removed / taken-down items usually stay unavailable. If Steam has pulled a Workshop item, anonymous login almost always still fails. That is a Steam restriction, not a fault in this app.
  • Some items need a real Steam account. Depending on the creator's privacy settings or the game's DRM, an item may be unreachable with login anonymous — which is all this app uses.
  • The App ID must match the item. A mismatched App ID makes SteamCMD report a generic failure that looks the same as a removed item.
  • Downloads run one at a time; a second request waits its turn.
